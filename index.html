📝 Utilisation

HTML : Utilisez l'attribut data-ds-toggle="ds-modal" sur le conteneur 
<div class="ds-modal" data-ds-toggle="ds-modal" id="myModal">
  <div class="ds-modal__dialog" role="dialog" aria-modal="true">
    <div class="ds-modal__header">
      <h2 class="ds-modal__title" data-ds-modal-title>Titre</h2>
      <button class="ds-modal__close" data-ds-modal-close>✕</button>
    </div>
    <div class="ds-modal__body">
      Contenu de la modale
    </div>
  </div>
</div>
JavaScript : Importer et utiliser le composant 
import { DsModal } from './ds-modal.js';

// Initialisation automatique
DsModal.startAutoInit();

// Ou initialisation manuelle
const modal = new DsModal(document.getElementById('myModal'));
modal.open();
modal.close();

  • Appuyant sur la touche Échap
